# Start Dev

**Not in a queue, questions or cockpit chat.** If `/queue` ran earlier in this
chat, a pasted `Use the start-dev skill. <path>` line (the dashboard's 📋 text),
prompt, path or title means "add it to `queue.md`": follow
[`../queue/queue.md`](../queue/queue.md). In a `/questions` chat, an answer or a
pasted `Use the questions skill. Q<n>` line is recorded through
[`../questions/questions.md`](../questions/questions.md), never started. In a
`/cockpit` chat, a paste means "`/add` it to the running shift": follow
[`../cockpit/cockpit.md`](../cockpit/cockpit.md). If two or more of `/queue`,
`/questions` and `/cockpit` ran in this chat, ask which one the paste is for.
Each way, stop here.

Follow [`start_dev.md`](start_dev.md) in this directory exactly — the
authoritative workflow body. `reference.md` holds the long-form templates and
the branch survey; shared context and cross-harness notes are in
[`../WORKFLOW.md`](../WORKFLOW.md). Do not duplicate or reinterpret the
workflow here — if it changes, edit `start_dev.md`.

Read only the applicable step/environment from linked references, not all files.
Reuse unchanged instructions already loaded; follow [CONTEXT.md](../CONTEXT.md)
for bounded output and repository paths.
