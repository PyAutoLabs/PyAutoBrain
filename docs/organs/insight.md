# Insight — PyAutoInsight

[Dashboard](https://pyautolabs.github.io/PyAutoInsight/) · [Repository](https://github.com/PyAutoLabs/PyAutoInsight)

Insight coordinates inference campaigns and pending domain tasks through one
editable all-inference check-in prompt, campaign table and task list. Results,
diagnostics, provenance and coverage follow below. A tracked campaign is not a
claim that a compute job is running.

It owns the instance registry, versioned `inference-summary` exchange contract,
ingest receipts, last-good evidence snapshots and cross-project dashboard.
`autolens_inference` is the initial real producer; a fixture tests another
producer without claiming another adoption. Producers retain their dashboards,
execution drivers, results and raw samples. Organ and project feed identities
remain separate; the cockpit reads only the organ feed.

## Ownership and routing

Start with `PyAutoInsight/CHECKIN.md`, adding campaign focus or ideas before or
after the prompt without dropping the overall sweep. Verified updates and their
sources are recorded durably in Insight. Refreshing evidence neither records a
human check-in nor changes task or scientific status. Copy controls execute
nothing and confer no compute approval.

Cortex remains authoritative for scientific run records, observations and human
conclusions. Mind retains bounded implementation PR lifecycle and repository
claims. Insight links both rather than maintaining independently editable copies.
Use existing project drivers, Brain faculties and development routes; there is
no inference conductor and the retired inference programme stays retired.

## Reading evidence

Integrity, freshness, execution status and scientific qualification are separate.
Unknown provenance stays unknown. Cached evidence retains its source age.
Failed seeds, partial pipelines and missing diagnostics or archives remain
visible. Comparison groups are producer-declared; incompatible runs are never
ranked. Overlapping stage times are not blindly summed. Heart alone owns release
readiness; Insight never turns process completion into scientific success.

## Design history

The 1 October proposal `research/profiling_inference_organs.md` established the
project/organ split. The 2–3 October Pulse implementation expanded ownership to
campaign intent and pending domain tasks. Insight follows that later model,
including migration mappings and the single-chat control room, rather than the
original evidence-only boundary. The human selected PyAutoInsight on 4 October
2026; canonical order is immediately after Pulse.
